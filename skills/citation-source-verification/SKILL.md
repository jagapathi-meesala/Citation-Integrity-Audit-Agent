# Citation Source Verification

- Treat local format checks as preliminary only.
- Verify author, title, date, venue, and persistent identifier against the original publisher record or a trusted scholarly index.
- Record which source was checked and what fields it supports.
- Escalate conflicting metadata for human review; never silently overwrite the original.
